# TER-67 三轴拓扑与几何 JSON 2.0

## 问题定位

旧算法存在两个会互相放大的限制：

1. 三轴候选只要三维 AABB 对较小特征的覆盖率超过 60%，就按形状优先级删除其中一个。两个真实正交孔或交叉槽也可能因此丢失。
2. JSON 只有 `Positive_Pillars` / `Negative_Holes` 两个低层桶。矩形轮廓被归为 `Unknown`，椭圆容易被归为胶囊；孔的贯通性、沉孔台阶、槽、凹槽、凸台、加强筋和阵列关系没有算法字段。

## 新算法

- 跨轴相交不再触发删除。仅对同轴、同形状、同尺寸和同位置的数值重复项去重。
- 使用形状参数构造三维包围盒，而不是对胶囊、矩形和多边形统一套用等效圆直径。
- 输出 `orthogonal_intersection`、`projection_overlap`、`cuts`、`coaxial_cut` 等显式关系；高置信度的正实体侧投影保留为 `Projection_Evidence`，但不重复计作独立实体。
- 结合轮廓形状、极性、轴向边界、切片间距、深度占比和直径阶段，派生语义类型与置信度。
- 对同类、同轴、近似同尺寸的三个以上特征执行二维分布分析，识别线性阵列、圆周阵列或普通重复组。
- 动态细切匹配由孔/柱扩展到槽、凹槽、口袋、凸台、加强筋、沉孔和台阶孔。

## 离线回放

对既有 Terra 29 份 `*_features.json` 做纯算法回放（不调用模型）：

| 指标 | 结果 |
| --- | ---: |
| 输入 JSON | 29 |
| 语义特征 | 211 |
| 语义类别 | 15 |
| 三维拓扑关系 | 308 |
| 正交相交关系 | 37 |
| 投影重叠关系 | 47 |
| 特征阵列 | 9 |

识别类别包括通孔、盲孔、内部孔、台阶孔、通槽、盲槽、通口袋、凸台、圆柱体、台阶凸台、棱柱凸台和加强筋等。该回放用于证明输出覆盖度与结构稳定性，不等同于人工标注精度；后续可用带特征级 GT 的数据计算各语义类别 precision/recall。

## 端到端几何验证

使用程序生成的 `10 × 10 × 6 mm` 环形实体执行完整 `STL → 三轴 SVG → JSON` 流程：

- 切片间距被写入 JSON（X/Y `0.33 mm`，Z `0.25 mm`）。
- 内环被识别为 `Through_Hole`，而不是因末层位于实体边界内侧而误判为盲孔。
- 外圆柱和通孔得到 2 个 canonical 特征；10 个侧视矩形候选仍作为可审计投影证据保留，但不会重复计数。
- 第一 Agent 的“通孔”坐标可直接匹配 `Recognized_Features` 并恢复完整 Z 轴细切范围。

## 兼容性

原有 `Positive_Pillars`、`Negative_Holes`、动态切片输入及渲染流程保持兼容。新增字段为：

- `Feature_Schema_Version`
- `Slice_Metadata`
- `Recognized_Features`
- `Feature_Relationships`
- `Feature_Patterns`
- `Profile_Transitions`
